# Диагностика на macOS

Файл: `collect_macos_diag.command`. Скрипт **только читает** настройки Mac. Пароль администратора не нужен, ничего не устанавливается.

Проверяются четыре сервиса: ChatGPT, Claude, Gemini, NotebookLM.

## Как выполнить (по шагам)

1. Включите VPN и откройте браузер так, как обычно работаете — тогда отчёт покажет именно вашу проблему.
2. Нажмите `⌘ + Пробел`, наберите `Терминал`, нажмите `Enter`.
3. Скопируйте строку ниже целиком и вставьте её в окно Терминала.
4. Нажмите `Enter` и подождите 40–60 секунд.
5. На экране появится отчёт из 9 разделов. Прокрутите окно вверх до первой строки.
6. Нажмите `⌘ + A`, затем `⌘ + C` — весь текст скопируется.
7. Вставьте текст в чат поддержки. Или сделайте снимок окна: `⌘ + Shift + 4`.
8. Закройте окно Терминала: `⌘ + Q`.

Команда для копирования:

```
curl -fsSL https://raw.githubusercontent.com/VladimirNNOV/vsemdostup-support/main/macos/collect_macos_diag.command | bash
```

## Если команда не сработала

- **«command not found: curl»** — macOS 10.14 и старше. Откройте страницу
  `https://raw.githubusercontent.com/VladimirNNOV/vsemdostup-support/main/macos/collect_macos_diag.command`, нажмите «Сохранить как…», затем в Терминале
  выполните `bash ~/Downloads/collect_macos_diag.command`.
- **«Operation not permitted»** — пришлите в поддержку скриншот окна.
- **Отчёт короче 9 разделов** — сеть оборвалась. Запустите команду ещё раз.

## Что показывает отчёт

1. Версия macOS и архитектура.
2. Системный прокси.
3. Маршрут по умолчанию и туннели `utun`.
4. DNS и адреса четырёх сервисов: настоящий, подмена провайдера, внутренний адрес VPN (fake-IP).
5. VPN-приложения и конфигурации.
6. Файл `/etc/hosts`.
7. Выход в интернет: адрес, страна, протокол, IPv4 и IPv6.
8. Ответ четырёх сервисов: маршрут, код по имени, код по настоящему адресу, время.
9. Итог простыми словами.

## Границы

- Работает только на macOS; на другой системе завершается с сообщением.
- Личные файлы, историю браузера и ключи подписки не читает.
- Исходящие запросы: `cloudflare.com/cdn-cgi/trace`, `api.ipify.org`, `api6.ipify.org`,
  `chatgpt.com`, `claude.ai`, `gemini.google.com`, `notebooklm.google.com`.
