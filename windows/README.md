# Диагностика на Windows

Файл: `collect_windows_diag.ps1`. Скрипт **только читает** настройки Windows. Пароль администратора не нужен, ничего не устанавливается.

Проверяются четыре сервиса: ChatGPT, Claude, Gemini, NotebookLM.

## Как выполнить (по шагам)

1. Включите VPN и откройте браузер так, как обычно работаете — тогда отчёт покажет именно вашу проблему.
2. Нажмите `Win`, наберите `PowerShell`, нажмите `Enter`. Откроется синее окно.
3. Скопируйте строку ниже целиком и вставьте её в окно. Вставка: правой кнопкой мыши.
4. Нажмите `Enter` и подождите 40–90 секунд. Строка скачает файл во временную папку и запустит его.
5. На экране появится отчёт из 8 разделов.
6. Выделите весь текст: `Ctrl + A`. Скопируйте: `Ctrl + C`.
7. Вставьте текст в чат поддержки. Или сделайте снимок окна: `Win + Shift + S`.
8. Закройте окно: `Alt + F4`.

Команда для копирования (одна строка):

```
powershell -NoProfile -ExecutionPolicy Bypass -Command "iwr -UseBasicParsing 'https://raw.githubusercontent.com/VladimirNNOV/vsemdostup-support/main/windows/collect_windows_diag.ps1' -OutFile $env:TEMP\vsem-diag.ps1; & $env:TEMP\vsem-diag.ps1"
```

Если PowerShell пишет «не удаётся загрузить файл» — проверьте интернет и запустите строку ещё раз.

## Почему не «одной командой в конвейере»

Файл содержит русский текст. При запуске через конвейер PowerShell 5.1 спотыкается на служебном
символе в начале файла и печатает ошибку про `#`. Поэтому клиент скачивает файл во временную
папку и запускает его как файл: тогда русский текст читается верно.

## Что показывает отчёт

1. Версия Windows и архитектура.
2. Системный прокси (параметры Windows и WinHTTP).
3. Маршрут по умолчанию и VPN-адаптеры: идёт ли трафик через VPN.
4. DNS-серверы и адреса четырёх сервисов: настоящий, подмена провайдера, внутренний адрес VPN.
5. Файл `hosts`.
6. Выход в интернет: адрес, страна, протокол, IPv4 и IPv6.
7. Ответ четырёх сервисов: маршрут, код по имени, код по настоящему адресу, время.
8. Итог простыми словами.

## Границы

- Работает только на Windows; на другой системе завершается с сообщением.
- Личные файлы, историю браузера и ключи подписки не читает.
- Для кодов ответа используется `curl.exe` (входит в Windows 10 и 11). Если его нет, берётся
  встроенный веб-запрос PowerShell.
- Исходящие запросы: `cloudflare.com/cdn-cgi/trace`, `api.ipify.org`, `api6.ipify.org`,
  `chatgpt.com`, `claude.ai`, `gemini.google.com`, `notebooklm.google.com`.
