# VsemDOSTUP — диагностика для клиентов

Два скрипта: для macOS и для Windows. Оба **только читают** настройки сети и делают до 12
сетевых GET-запросов к публичным адресам. Ничего не меняют, ничего не устанавливают, файлов
не создают, ключей и паролей не печатают. Пароль администратора не нужен.

## Выберите систему

| система | папка | файл |
|---|---|---|
| macOS (Apple) | [`macos/`](macos/) | `collect_macos_diag.command` |
| Windows | [`windows/`](windows/) | `collect_windows_diag.ps1` |

В каждой папке — пошаговая инструкция и готовая команда для копирования.

## Какие ИИ-сервисы проверяются

ChatGPT (`chatgpt.com`), Claude (`claude.ai`), Gemini (`gemini.google.com`),
NotebookLM (`notebooklm.google.com`). По каждому сервису — две проверки: обычный запрос
по имени и запрос к настоящему адресу сервиса. Это и отличает проблему DNS от проблемы канала.

## Что общего в отчётах

1. Версия системы и архитектура.
2. Системный прокси.
3. Маршрут по умолчанию: идёт ли трафик через VPN.
4. DNS и адреса всех четырёх сервисов: настоящий, подмена провайдера, внутренний адрес VPN.
5. VPN-программы, подключения, процессы.
6. Файл `hosts`.
7. Выход в интернет: адрес, страна, IPv4 и IPv6.
8. Ответ четырёх сервисов по имени и по настоящему адресу.
9. Итог простыми словами: что сломано — DNS, маршрут, канал или браузер; отдельно — нужен ли
   выход из США для Gemini и NotebookLM.
