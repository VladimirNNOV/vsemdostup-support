# VsemDOSTUP — диагностика на macOS

Один файл: `collect_macos_diag.command`. Скрипт **только читает** настройки Mac и делает
до 6 сетевых GET-запросов к публичным адресам. Ничего не меняет, файлов не создаёт,
ключей и паролей не печатает.

## Как выполнить (по шагам)

1. Нажмите `⌘ + Пробел`. Наберите `Терминал` и нажмите `Enter`. Откроется чёрное окно.
2. Скопируйте строку ниже целиком и вставьте её в окно Терминала.
3. Нажмите `Enter` и подождите 20–40 секунд.
4. На экране появится отчёт из 9 разделов. Прокрутите окно вверх до первой строки.
5. Нажмите `⌘ + A`, затем `⌘ + C` — весь текст скопируется.
6. Вставьте текст в чат поддержки. Или сделайте снимок окна: `⌘ + Shift + 4`.
7. Закройте окно Терминала: `⌘ + Q`.

Команда для копирования (одна строка):

```
curl -fsSL https://cdn.jsdelivr.net/gh/VladimirNNOV/vsemdostup-support@main/collect_macos_diag.command | bash
```

Пароль администратора не нужен. Скрипт ничего не устанавливает.

Резервная ссылка, если эта не откроется:

```
curl -fsSL https://raw.githubusercontent.com/VladimirNNOV/vsemdostup-support/main/collect_macos_diag.command | bash
```

## Если команда не сработала

- **Терминал пишет «command not found: curl»** — macOS 10.14 и старше. Откройте страницу
  `https://raw.githubusercontent.com/VladimirNNOV/vsemdostup-support/main/collect_macos_diag.command`,
  нажмите «Сохранить как…», затем в Терминале выполните `bash ~/Downloads/collect_macos_diag.command`.
- **Терминал пишет «Operation not permitted»** — напишите в поддержку, пришлите скриншот окна.
- **Отчёт короче 9 разделов** — сеть оборвалась. Запустите команду ещё раз.
- **Ничего не помогает** — пришлите скриншот окна Терминала и напишите, на каком шаге остановились.

## Что показывает отчёт

1. Версия macOS и архитектура.
2. Системный прокси (HTTP/HTTPS/SOCKS) — включён или нет.
3. Маршрут по умолчанию и туннели `utun`: идёт ли трафик через VPN.
4. DNS-серверы и адрес, в который резолвится `chatgpt.com`. Скрипт отличает настоящий адрес,
   подмену провайдера и внутренний адрес VPN-приложения (fake-IP).
5. VPN-приложения, активные VPN-конфигурации, процессы.
6. Файл `/etc/hosts` (непустые строки).
7. Выход в интернет: адрес и страна, протокол (http/2 или http/3), IPv4 и IPv6 отдельно.
8. Ответ `chatgpt.com`: маршрут до сайта, код ответа по имени, код ответа по настоящему адресу,
   текст ошибки подключения, время системы.
9. Итог простыми словами: идёт ли ChatGPT через туннель, есть ли подмена DNS или fake-IP,
   нет ли утечки IPv6, в порядке ли сеть или причина в браузере.

## Границы

- Работает только на macOS; на другой системе завершается с сообщением.
- Личные файлы, историю браузера и ключи подписки не читает.
- Исходящие запросы: `cloudflare.com/cdn-cgi/trace`, `api.ipify.org`, `api6.ipify.org`, `chatgpt.com`.
