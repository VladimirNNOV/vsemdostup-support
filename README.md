# VsemDOSTUP — диагностика на macOS

Один файл: `collect_macos_diag.command`. Скрипт **только читает** настройки Mac и делает
4 сетевых GET-запроса. Ничего не меняет, файлов не создаёт, секретов не печатает.

## Запуск одной командой

```
curl -fsSL https://raw.githubusercontent.com/VladimirNNOV/vsemdostup-support/main/collect_macos_diag.command | bash
```

Скрипт печатает отчёт в окно терминала. Текст нужно скопировать или снять скриншот и прислать в поддержку.

## Что показывает

1. Версия macOS и архитектура.
2. Системный прокси (HTTP/HTTPS/SOCKS) — включён или нет.
3. Маршрут по умолчанию: идёт ли трафик через туннель `utun` или напрямую.
4. DNS-серверы и адрес, в который резолвится `chatgpt.com`.
5. VPN-приложения, системные расширения, активные VPN-конфигурации и процессы.
6. Файл `/etc/hosts` (непустые строки).
7. Куда выходит интернет: адрес и страна, IPv4 и IPv6 отдельно, протокол (http/2 или http/3).
8. Ответ `chatgpt.com`: код, время, адрес сервера.
9. Итог простыми словами: перехватывает ли VPN трафик, нет ли подмены DNS, нет ли утечки IPv6.

## Границы

- Работает только на macOS; на другой системе завершается с сообщением.
- Пароль администратора не требуется.
- Личные файлы, историю браузера и ключи подписки не читает.
- Исходящие запросы: `cloudflare.com/cdn-cgi/trace`, `api.ipify.org`, `api6.ipify.org`, `chatgpt.com`.
