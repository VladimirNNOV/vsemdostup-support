# Проверка на телефоне: iPhone и Android

На телефоне нет терминала, поэтому проверка сделана в двух видах.

| система | что доступно | что покажет |
|---|---|---|
| iPhone, iPad | страница-проверка в браузере | адрес и страна выхода, IPv4/IPv6, настоящие адреса четырёх сервисов, есть ли с ними связь |
| Android | страница-проверка в браузере | то же самое |
| Android | скрипт в Termux (полный аналог) | всё как на компьютере: маршрут, туннели, системные DNS, коды ответов |

## iPhone и Android: проверка в браузере (без установки)

1. Откройте ссылку:
   `https://vladimirnnov.github.io/vsemdostup-support/mobile/check.html`
2. Включите VPN и подождите 20–30 секунд — страница проверит всё сама.
3. Нажмите «Скопировать отчёт».
4. Вставьте отчёт в чат поддержки.

Страница ничего не устанавливает, пароль не спрашивает, файлов не создаёт.

Что она проверяет:

1. **Выход в интернет** — адрес, страна, протокол (через `cloudflare.com/cdn-cgi/trace`).
2. **IPv4 и IPv6** отдельно (через `api.ipify.org` и `api6.ipify.org`).
3. **Настоящие адреса** четырёх сервисов через защищённый канал DoH (`cloudflare-dns.com`).
   Провайдер не может подменить такой ответ.
4. **Связь с сервисами**: «отвечает», «ответ скрыт браузером, сеть есть» или «нет ответа».

## Android: полная проверка в Termux

Нужен Termux из F-Droid: `https://f-droid.org/packages/com.termux/`

1. Установите Termux (из F-Droid, не из Play Маркета — там версия устарела).
2. Откройте Termux и вставьте строку `pkg install curl -y`.
3. Затем вставьте вторую строку:
   `curl -fsSL https://raw.githubusercontent.com/VladimirNNOV/vsemdostup-support/main/mobile/collect_android_diag.sh | bash`
4. Дождитесь отчёта из 7 разделов, выделите текст и пришлите в поддержку.

Скрипт не требует root, ничего не меняет и не устанавливает.

## Границы

- Страница в браузере не видит системные адреса DNS и имя туннеля: браузер не даёт к ним доступ.
  Поэтому по сервисам она показывает «есть связь / нет связи», а не коды ответов.
- iOS: терминал установить нельзя, полного аналога на iPhone нет.
- Полный отчёт с DNS и маршрутом дают Termux на Android и скрипты для macOS и Windows.
